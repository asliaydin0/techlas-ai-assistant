# Sıfırdan Kendi Yapay Zekâmızı İnşa Ediyoruz

[TechLas Yazılım](https://instagram.com/techlas_) Instagram Reels serisinin öğretici kodları.

Seride tek bir dosyayı büyütüyoruz: `assistant.py`. Her bölüm bir önceki bölümün üzerine yeni bir yetenek ekler. Bu depodaki kod, videolarda ekranda görünen örneklerin çalıştırılabilir halidir.

> `llm`, `rag` ve `tools` dosyaları **öğretici taslaktır**. Gerçek bir dil modeline, e-posta servisine veya vektör veritabanına bağlanmazlar; API anahtarı da istemezler. Videodaki fikri kendi bilgisayarında görmen için yazılmışlardır.

## Nasıl çalıştırılır

Python 3 yeterlidir. Ek paket kurman veya API anahtarı girmen gerekmez.

```bash
cd 01-temel-cekirdek
python assistant.py
```

Aynı komutu diğer `01`–`04` klasörlerinde de kullanabilirsin. 5. bölüm henüz yapım aşamasındadır.
